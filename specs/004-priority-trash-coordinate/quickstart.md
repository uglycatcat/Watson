## Prerequisites

- Node.js 22+
- 已配置 `.env`（访问码、可选 LLM；本轮生命周期不依赖 LLM）
- 库位于仓库根目录

```bash
# 安装（若尚未）
cd backend && npm i && cd ../frontend && npm i

# 应用 migration（含 0002–0004）后启动单端口 — 以仓库现行脚本为准，例如：
cd backend && npm run db:migrate   # 若项目脚本名不同，见 package.json
# 启动 dev（单端口或前后端一并）
```

升级前若 DB 含旧枚举/截止型数据，确认 0002–0004 已按序执行。

## Smoke：迁移后数据

1. 打开应用，登录验证码。
2. 抽查原「高/中/低」卡：重要度/紧急度分别为 8/5/2 附近可编辑为任意 0..10。
3. 原**截止型**卡：应出现在**全部**且无时间（未安排）；不在日/周/月。
4. 原**持续型**卡：仍按起止出现在日历。

---

## 场景 A — 生命周期（SC-001 / SC-002）

1. 日或全部视图：点卡片侧完成方框 → 无确认 → 卡消失。
2. 打开垃圾箱：该项在左上附近，带**对勾**。
3. 另建卡 → 详情「删除」→ 确认 → 垃圾箱带**红圆**。
4. 对完成项点「恢复」→ 回到全部/对应日历；对删除项「永久删除」→ 确认后消失且搜索不到。
5. 恢复时若标题已被新 active 占用 → 应失败提示，卡仍在箱。

---

## 场景 B — 时间模型（SC-003）

1. 仅标题创建 → 只在全部可见。
2. 编辑补 `startAt` → 出现在对应日/周/月。
3. 表单无「时间性质」；不可只填结束时间而无起始。

---

## 场景 C — 优先级与坐标（SC-004 / SC-005）

1. 竖向选择器可选 0 与 10。
2. 日/全部打开坐标视图：原点观感在中央；同 (u,i) 聚合变大。
3. 悬停见任务名；**点击圆无跳转/无固定面板**。
4. 完成进箱的卡不在坐标中。

---

## 场景 D — 详情即时编辑（SC-006）

1. 改标题后点遮罩 → 再开仍为旧标题。
2. 再改 →「重置」回打开时值且不关。
3. 「确认」保存关闭；空标题/重名红字不关。

---

## 场景 E — 壳层与视觉（SC-007 / SC-008）

1. 冷启动：AI 隐藏；顶栏无登出、有垃圾箱；主题按钮显示「浅色」或「深色」。
2. 创建：Enter 与确认按钮均可建卡。
3. 缩窄窗口：日/全部列数变化优于单卡无限拉宽。
4. 周/月：左侧不破边；同列多卡可辨；月跨天略宽不跨格。

---

## 场景 F — 搜索含箱

1. 完成一张唯一标题卡。
2. 搜索该标题 → 候选标「已完成」→ 点开只读。
3. 永久删除后再搜 → 无结果。

## API 抽样（可选 curl）

需带会话 cookie。示例意图：

```http
POST /api/cards/:id/complete
GET  /api/cards?view=trash
POST /api/cards/:id/restore
DELETE /api/cards/:id/permanent
```

期望：常规 `view=all` 无箱内 id；`view=trash` 有。
