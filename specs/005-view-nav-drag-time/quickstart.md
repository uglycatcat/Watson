# Quickstart: 005 验证指南

**Feature**: `005-view-nav-drag-time`  
**Date**: 2026-07-16

## 前提

```bash
# 仓库根目录
cp .env.example .env   # 若尚未配置
npm install            # 或项目既定安装方式
npm run dev            # 单端口前后端
```

浏览器打开应用根 URL，使用测试账号登录。可选：若存在 `0005_backfill_end_at`，先跑迁移/SQL。

契约详见 [data-model.md](./data-model.md)、[contracts/](./contracts/)。

---

## V1 时间三种互斥态

1. 新建卡：不填时间 → 未安排（日程视图不出现）。
2. 只填结束 → 保存后有开始（约等于创建/现在）且有结束。
3. 只填开始 → 结束自动为开始+24h；改开始时若结束空或早于新开始则重算，否则保留结束。
4. 已安排卡清空一端再保存应被拦或自动补齐为合法态。

---

## V2 拖拽进箱

1. 桌面（精细指针）：从日/全部卡片或周条拖到 TopBar 垃圾箱图标（含扩大热区）→ 进箱，无确认。
2. 详情内点删除 → 仍有确认。
3. 窄屏/触摸/粗指针：可不提供拖拽；用详情删除完成同等归档。
4. 模拟删除失败（如断网）：卡片仍活跃并有失败提示，无「列表消失但未进箱」。

---

## V3 日期导航

1. 日/周/月：前后翻页与「今天/本周/本月」生效。
2. 全部视图：TopBar 仍显示日期；改日期不改变全部列表过滤。
3. 日期控件无法清空；「回到今天」将锚点设为今天。
4. 垃圾箱视图：隐藏日期控件。

---

## V4 日视图坐标

1. 日视图右侧常驻坐标图（凹陷方框），无切换按钮。
2. 全部视图仍用按钮弹出坐标。

---

## V5 登录占位与视觉

1. 登录页底有备案占位区（主题适配）。
2. 周条更粗、略下移；周/月框底边有留白。

---

## 预期结果摘要

| 场景 | 通过标准 |
|------|----------|
| 时间 | 库中无「单端有值」持久态；结束≥开始 |
| 拖拽 | soft 后卡在垃圾箱；桌面无二次确认 |
| 导航 | anchor 永非空；all 不滤日期 |
| 日视图 | 右侧常驻象限；无日视图按钮 |

失败时对照 `contracts/api-usage.md` 与 `research.md` 决策项排查。
