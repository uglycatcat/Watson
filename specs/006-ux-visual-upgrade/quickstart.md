# Quickstart: 006 验证指南

**Feature**: `006-ux-visual-upgrade`  
**Date**: 2026-07-16

## 前提

```bash
# 仓库根目录
cp .env.example .env   # 若尚未配置
npm install
npm run dev
```

浏览器登录。契约见 [data-model.md](./data-model.md)、[contracts/ui-components.md](./contracts/ui-components.md)。  
**本轮无 migration、无后端重启要求**（纯前端）。

---

## V0 设计 Token 与主题

1. 切换浅色/深色：背景、面板、强调色过渡顺滑（约 200ms），非瞬间跳变。
2. 抽查按钮、卡片、输入框：圆角/间距/阴影同类一致。
3. 浅色强调色为蓝、深色为 NVIDIA 绿；整体仍「简洁 + 科技感」。

---

## V1 动效与无障碍

1. 打开/关闭创建弹层、详情弹层、AI 侧边栏：淡入淡出，非硬切。
2. 悬停顶栏按钮、分段项：短促颜色过渡。
3. **系统开启「减少动态效果」**（OS 或 DevTools 模拟 `prefers-reduced-motion: reduce`）：
   - 上述动效几乎即时；
   - 完成勾选、拖拽垃圾箱仍有状态变化；
   - 功能与 005 一致。

---

## V2 顶栏三区与分段控件

1. 识别左（品牌+搜索+新建）、中（日/周/月/全部分段 + AnchorDate）、右（操作区）。
2. 分段控件**仅**四视图；垃圾箱**不在**分段内，为右侧独立入口。
3. ViewTimeNav 仍在日/周/月视图内（不在顶栏）。
4. 搜索框默认较窄；聚焦可展开；搜索行为与 003 一致。
5. 垃圾箱与主题/AI 有视觉分组（分隔线或间距）。
6. **005 回归**：日期不可清空、回到今天、all 显示日期但不滤列表、trash 无日期。

---

## V3 卡片与优先级可视化

1. 活跃卡片：左缘分类色带；标题 > 时间 > 标签/优先级层级清晰。
2. 重要度/紧急度为 **强度条 + 梯度色**；数字仅辅助，无「重要5 紧急5」主展示。
3. 深色模式卡片与背景有清晰层次（阴影/抬升）。
4. 完成勾选：hover 反馈 + 勾选动效；完成后业务同前。
5. 点击卡片、拖拽删除：**行为不变**。

---

## V4 坐标图四象限

1. **日视图**右侧常驻区：四象限淡背景 + 立即做/计划做/授权做/减少做标签。
2. 横轴「紧急度」、纵轴「重要度」、原点 (5,5) 深浅主题均可读。
3. **全部视图**仍按钮打开浮层；取数范围同 005。
4. 悬停点：tooltip 含标题与优先级信息。
5. 0～1 个点：有说明文案，非空白。
6. 点击点无新导航。

---

## V5 空状态、骨架、Toast

1. 清空或筛选至无数据：日/周/月/全部/垃圾箱均显示图标 + 文案 + 主操作按钮。
2. 搜索无匹配：有引导（非空白下拉）。
3. 刷新或切换视图：加载中见骨架，非长时间白屏或纯「加载中…」文字。
4. 创建 / 完成 / 删除 / 恢复 / 永久删除成功：轻量 toast 自动消失，可继续操作。
5. 快速连续操作：toast 不严重堆叠遮挡。

---

## V6 拖拽垃圾箱反馈

1. 桌面拖活跃卡至垃圾箱：图标进入激活高亮态。
2. 拖离或未命中：激活消退，卡不进箱。
3. 松手于垃圾箱：进箱无二次确认；详情删除仍有确认（005）。

---

## V7 登录页

1. 构图平衡，备案占位（005）仍协调。
2. 品牌标题质感克制，无廉价高饱和描边。
3. 验证码框对比充足 + 「四字符验证码」引导。
4. 登录成功流程不变。

## 失败排查

| 现象 | 查 |
|------|-----|
| 样式不一致 | `index.css` token 是否被组件硬编码覆盖 |
| 动效过长 | `--duration-*` 与 reduced-motion 媒体查询 |
| Toast 不出现 | `ToastProvider` 是否包裹、`onSuccess` 是否挂载 |
| 色带不对 | `getCategoryAccent(categoryId)` |
| 功能坏了 | 是否误改 `useCardMutations` mutationFn 或 API 层 — **应只改 onSuccess 与 JSX** |
