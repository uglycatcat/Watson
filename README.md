# Watson · 你的 AI 日程助手

> **一个专为「我自己」打造的个人日程管理工具。** 左边看日程，右边跟 AI 聊天，把你的日历、待办和复盘都放在一个地方。打开浏览器就能用，手机、平板、电脑都行。

---

## 这是什么

Watson 把你的日程当成一张张**卡片**来管。每件事情就是一张卡，有时间、有重要程度、有分类，你可以用日历也可以用列表看它们，还能丢进回收站、拖来拖去。

它不是团队协作工具，也不是通用日历——它只服务你一个人，所以登录很简单（一个验证码），界面也安静。

---

## 你能用它做什么

### 🗂️ 用卡片管理每件事
每张日程卡片可以设：
- **时间**：要么是一段时间（如「周五 15:00–16:00 开会」），要么是一个截止日（如「周五前交报告」）
- **重要程度 + 紧急程度**：两个维度组成「四象限」，帮你分清什么该先做
- **分类 + 颜色**：工作/生活/学习…自定义，卡片左侧有颜色标记
- **进行阶段**：未开始 / 进行中 / 收尾中
- **父子卡片**：把几件小事组合成一个大任务

### 📅 多种视图看日程
- **日 / 周 / 月视图**：熟悉的日历方式
- **全部视图**：所有卡片平铺，支持按分类/重要度/时间筛选和排序
- **四象限视图**：按「重要×紧急」四格分布，一眼看出该优先处理什么
- **回收站**：删错了可以找回来

### 💬 跟 AI 聊天
右侧常驻一个 AI 聊天栏，你可以用大白话跟它交流、问它问题。

> ℹ️ **当前版本说明**：AI 聊天栏目前是**纯对话**（能聊天、答疑），**还不会自动帮你增删改日程**。日程的创建和修改请直接在左侧界面操作。（让 AI 直接操作日程是规划中的能力。）

### 📝 每日复盘
每天可以写下「目标 / 结果 / 复盘」，用来回顾和总结。

### 🌙 其他
- 明 / 暗两种主题
- 全局搜索（按标题快速找卡片）
- 多设备同步：手机改了，电脑上也同步看到

## 🚀 在本地预览效果

想在自己电脑上先跑起来看看？按以下步骤（Windows / macOS / Linux 通用）。

### 前提
- 装好 **[Node.js](https://nodejs.org/) v22** 以上（自带 npm）。在终端/命令行跑 `node -v` 能看到版本就行。

### 第一步：拿到代码并安装依赖
```bash
git clone https://github.com/uglycatcat/Watson.git
cd Watson
npm install          # 第一次会装一会儿，耐心等
```

> 💡 如果 `npm install` 卡在 `better-sqlite3` 报错：Windows 上需要装 **Visual Studio Build Tools（勾选 C++ 工作负载）+ Python**；macOS 需要 `xcode-select --install`。多数情况下会直接下好、不需要编译。

### 第二步：配置
```bash
cp .env.example .env
```
用文本编辑器打开 `.env`，至少填一下：

| 配置 | 填什么 |
|---|---|
| `SESSION_SECRET` | 随便一串 16 位以上的字符（本地预览随便填即可） |
| `LLM_API_KEY` | 你的 AI 密钥（不填也能用，只是 AI 聊天栏不可用） |
| `LLM_PROVIDER` | `openai` / `deepseek` / `anthropic` 三选一 |
| `LLM_BASE_URL` | 对应服务的接口地址 |
| `LLM_MODEL` | 模型名，如 `gpt-4o-mini`、`deepseek-chat` |

只想看界面、不用 AI？`SESSION_SECRET` 随便填一串就能跑，其他留空也行。

### 第三步：启动（开发预览）
```bash
npm run dev
```
启动后浏览器打开 **http://localhost:5173** —— 这就是开发预览地址（改代码会自动刷新）。

登录页输入验证码 **`ANNA`** 即可进入。

### 想看「正式上线」的效果？
```bash
npm run build        # 打包前后端
npm start            # 启动
# 然后浏览器打开 http://localhost:3001
```
这种方式前后端合并在一个端口（3001），更接近真实部署的样子。

## 常见问题

**Q: 登录验证码是什么？**
A: 默认 `ANNA`。正式部署时可以用环境变量 `WATSON_ACCESS_CODE` 改成你自己的。

**Q: 一定要配 AI 密钥吗？**
A: 不用。不配的话日程管理全部功能都能用，只是右侧 AI 聊天栏不能聊。

**Q: 支持哪些 AI？**
A: OpenAI、DeepSeek、Anthropic（Claude），以及任何 OpenAI 兼容接口。在 `.env` 里切换。

**Q: 数据存在哪？**
A: 本地 `data/watson.db`（SQLite 文件），全部在你自己机器上，不会上传到任何地方。

**Q: 手机上能用吗？**
A: 能。部署到公网服务器后，手机/平板/电脑用浏览器打开同一个地址即可，无需装 App。
